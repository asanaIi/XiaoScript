# XiaoScript

**XiaoScript** — это экспериментальный гибридный язык программирования, вдохновленный экосистемой устройств Xiaomi, MIUI и HyperOS. Он объединяет в себе декларативность XML для конфигурации «железа», производительность C++ ядра и гибкость JavaScript для реализации игровой и программной логики.

## Особенности

* **XML-Манифесты**: Настройки аппаратной части смартфона или приложения объявляются внутри тегов `<Device>`.
* **JS-Логика**: Окно приложения и игровой процесс описываются на стандартном JavaScript внутри тегов `<App>`.
* **Кастомные комментарии**: Игнорирование неважных строк с помощью синтаксиса `<! это комментарий !>`.
* **Монолитное C++ ядро**: Быстрый парсинг, очистка кода и сборка финального исполняемого контекста.

---

## Архитектура проекта

* `runtime.cpp` — Монолитный движок на C++. Отвечает за чтение файлов `.xiao`, удаление комментариев, сборку переменных из XML и подготовку JS-окружения.
* `XiaoScriptBridge2.js` — Главный системный мост. Автоматически компилирует C++ ядро при первом запуске и передает сценарии на исполнение.
* `main.xiao` — Файл исходного кода (например, игра Змейка).

---

## Требования

Для работы интерпретатора на компьютере должны быть установлены:

1. **Node.js** (версии 16 или выше)
2. **Компилятор C++** (`g++` с поддержкой стандарта C++17)

---

## Запуск проекта

Вы можете запустить исходный код напрямую через Node.js мост:

```bash
node XiaoScriptBridge2.js main.xiao

```

Мост автоматически проверит наличие скомпилированного ядра `runtime`, соберет его при необходимости и выполнит сценарий.

## Настройка глобального CLI (`xiaoscript`)

Чтобы запускать файлы красивой короткой командой прямо в терминале, выполните локальную настройку под вашу операционную систему:

### Для Linux / macOS:

Создайте символическую ссылку в системной папке:

```bash
sudo ln -s "$(pwd)/XiaoScriptBridge2.js" /usr/local/bin/xiaoscript
chmod +x /usr/local/bin/xiaoscript

```

### Для Windows:

1. Создайте файл с именем `xiaoscript.cmd` в любой папке, которая добавлена в системную переменную `PATH` (например, `C:\Windows`).
2. Запишите в него следующий код, указав точный путь к вашему проекту:

```cmd
@echo off
node "C:\путь_к_папке_проекта\XiaoScriptBridge2.js" %*

```

После этого вы сможете запускать любые скрипты из любой папки одной командой:

```bash
xiaoscript main.xiao

```
